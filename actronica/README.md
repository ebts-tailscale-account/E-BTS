# Tactile Lab Generator — генератор тактильных сигналов для Actronica HSD

Запуск (двойной клик или из терминала):

```
python tactile_generator.pyw
```

Зависимости (один раз на каждом компьютере, из папки `actronica`):

```
pip install -r requirements.txt
```

Это `numpy`, `sounddevice` и `soundcard`. `soundcard` нужен только для музыки с компьютера (Audio in) — без него программа работает, но Audio in слушает лишь микрофон. Старый `test.py` не тронут.

## Что умеет

| Блок | Возможности |
|---|---|
| **Генераторы A и B** | Два независимых источника. Формы: Sine, Square (скважность + сглаживание фронтов), Triangle (симметрия), Saw, Noise, Rumble (плавный случайный сигнал). Частота 5–1000 Гц (лог. шкала), амплитуда, фаза. |
| **Audio in (музыка → вибрация)** | Генератор слушает системный звук (loopback колонок/наушников) или микрофон. Режимы: **Bass** — низы из музыки идут на актуатор напрямую; **Envelope** — громкость баса управляет несущей (по умолчанию 65 Гц, резонанс HapCoil); **Beats** — удар на каждую бочку. Чувствительность, полоса, release / затухание удара, порог бита, шумовой гейт, авто-уровень. Задержка ~40–80 мс. Работает с любым источником: Spotify, YouTube, игры. |
| **Модуляция** | AM (пульсация/«дыхание»), FM (вибрато), Sweep (лог. развёртка частоты, ping-pong). Во время развёртки кнопка **M** запоминает текущую частоту — так удобно искать резонанс актуатора; клик по метке ставит эту частоту. |
| **Burst / pulse train** | Пачки: время вкл/выкл в мс, плавные фронты (без щелчков), опционально фаза с нуля в каждой пачке. |
| **Outputs (20 каналов)** | Каждому каналу назначается A / B / A+B / off, своя громкость (колесо мыши), протяжка мышью для назначения сразу нескольких. Индикатор уровня на каждом канале. |
| **Spatial pattern** | Static, Chase, Ping-pong, Random — сигнал «бегает» по включённым каналам с настраиваемым шагом и кроссфейдом. |
| **Effects** | 12 одиночных эффектов (Click, Tick, Thud, Heartbeat, Bounce, Buzz, Alert, Ramp, Rumble, Rev) на клавишах 1–0, −, =. |
| **Scope** | Осциллограф с синхронизацией (10 мс – 1 с) и спектр (FFT, дБ). Показывает A, B и реальный выход выбранного канала (Shift+клик по каналу). Без подключения — превью. |
| **Master** | Громкость и защитный лимит (жёсткое ограничение + индикатор CLIP). |
| **Пресеты** | 12 встроенных (в т.ч. Music feel, Music + beats) + Save/Load в JSON. Последняя сессия сохраняется автоматически (`tactile_generator/session.json`). |

## Устройство

- Плата ищется по имени `HSD`, а не по номеру устройства (ID в Windows меняются при переподключении). Сначала пробуется WASAPI exclusive, при ошибке — shared.
- После запуска поток открыт, но на выходе тишина, пока не нажат **Play** (Space).
- Для Audio in музыка должна играть на колонках/наушниках, выбранных в панели Audio input, а **не** на HSD (саму плату программа не слушает — иначе была бы петля). Захват включается только пока какой-то генератор в режиме Audio in. Если в Windows выходом по умолчанию стоит HSD, Spotify и браузер играют в плату, и захватить музыку нельзя: поставьте по умолчанию Speakers/Headphones (Параметры → Система → Звук → Вывод) или выберите их в Spotify.
- **Esc** — мгновенно заглушить всё. **Tab** — переключить A/B.
- Если устройство не видно — проверьте, что USB-кабель с линиями данных (как выяснилось с кабелем от зарядки), и нажмите ↻.

## Структура

```
tactile_generator/
  dsp.py      генераторы, модуляции, burst, пространственные паттерны, эффекты (numpy)
  audio_in.py захват системного звука / микрофона и анализ музыки (бас, огибающая, биты)
  engine.py   аудиопоток sounddevice, микширование в N каналов, лимитер, буфер осциллографа
  widgets.py  тёмная тема и виджеты на tkinter Canvas
  app.py      интерфейс
  presets.py  встроенные пресеты
```
